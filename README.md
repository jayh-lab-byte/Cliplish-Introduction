# Cliplish Landing Page

첨부된 Google Stitch 디자인을 재사용한 정적 마케팅 웹사이트입니다.

## 바로 보기
압축을 해제한 후 `dist/index.html`을 브라우저로 열면 됩니다. 이미지와 폰트가 포함되어 있습니다.

## 수정 및 빌드
Node.js 20 이상에서:

```sh
npm install
npm run build
npm run preview
```

미리보기 주소: http://127.0.0.1:4173

- `index.html`: 페이지 구조와 문구
- `input.css`, `tailwind.config.cjs`: 디자인과 반응형 스타일
- `assets/`: 원본 이미지, 폰트, 컴파일된 CSS
- `dist/`: 배포용 완성본
- `vercel.json`: Vercel 빌드 설정

모든 서비스 시작 링크는 `http://cliplish.vercel.app/`로 연결됩니다.
앱의 저장·재생 화면은 디자인 예시이며 실제 앱 기능은 구현하지 않았습니다.
원본에 프로젝트 저장소 주소가 없어 GitHub 링크는 원본의 https://github.com 을 유지합니다.
